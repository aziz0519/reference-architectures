# Deploying a 3 Tier Architecture Network in AWS
> Separate web, application and database layers usually on different servers or services

## Context Diagram

![3-Tier-AWS](/networking/images/3_tier_aws.jpeg)

## Advantages of 3-Tier 
* Independent scaling for each tier
* Better security and network control
* Easier deployment maintenance 
* More reliable and production-ready

## Disadvantages of 3-Tier
* More complex to setup and manage
* Higher cost
* Network latency between tiers
* More components to monitor and secure
* Requires proper network configuration (security group, firewalls)
